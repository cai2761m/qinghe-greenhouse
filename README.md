# 青禾 · 数字大棚

使用 Vue 3、TypeScript 和 Vite 构建的数字大棚管理界面。根据草图保留实时环境报告、树莓派 5B、PLC 控制器及运行日志布局。

## 本地运行

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

## 功能

- 三个大棚切换；温湿度、光照、CO₂ 和土壤湿度每 5 秒随机更新，支持暂停与手动刷新。
- 树莓派和西门子 S7-200 SMART 设备示意、运行状态和详情。
- 循环风机、滴灌水泵、补光灯、遮阳帘模拟开关，支持自动/手动模式选择。
- 温湿度阈值设置、环境预警、本地设置持久化。
- 环境趋势图，支持温度/湿度及 1 小时/24 小时/7 天切换、悬停查看。
- 运行日志分类、搜索、最近一小时过滤、分页和 CSV 导出。
- 响应式布局与移动端侧边导航。

所有传感器、设备、控制模式和运行记录均为演示模拟；没有连接树莓派、PLC 或外部服务。趋势曲线为随机演示数据，不代表真实历史记录。刷新后运行日志重建，设备状态和阈值设置保存于当前浏览器 localStorage。
